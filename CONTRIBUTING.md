# Contributing

Bug reports and ideas are welcome as GitHub issues. For a bug, say what you did, what
you expected and what happened, plus your OS and Claude Code version (`claude --version`).
Never paste anything from `credentials\` or `.credentials.json`.

Pull requests: keep them small and focused, run `cargo test`, `cargo clippy` and
`pnpm exec tsc --noEmit`, and follow [DEVELOPMENT.md](DEVELOPMENT.md). Contributions are
accepted under the project's license ([LICENSE.md](LICENSE.md)).
